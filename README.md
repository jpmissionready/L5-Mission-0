## About the Project

Mission 0 is a one-page test project that we have created for Marketing Association New Zealand's new digital news homepage. Built with a front-end framework (React), with its own colours and pictures. The page is mobile responsive. 

### Built with

* React
* Vite

## Getting Started

To get a local copy, follow the steps below.

### Prerequisites

* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/jpmissionready/L5-Mission-0.git
   ```
2. Install NPM packages
   ```sh
   npm install
   ```
3. Run the project
   ```sh
   npm run dev
   ```
